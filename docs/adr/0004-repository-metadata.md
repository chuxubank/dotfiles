# Separate repository metadata from paths

`path.toml` consumers require string leaves and care only where resources live. Embedding clone URLs, branches, refresh periods, and host conditions there would make every path lookup understand repository metadata. Keeping those facts in per-group external templates had the opposite problem: paths and clone behavior were split across files, every group reimplemented rendering and gating, and a new path key did not reveal whether it needed a clone.

`repositories.yaml` now maps a `path.toml` key path to git clone metadata. Its interface is `path`, optional `dest`, `url`, `refresh_period`, optional `branch`, optional `depth`, optional `upstream`, and optional shared `when` conditions. `repositories.toml.tmpl` resolves and validates paths, evaluates host conditions, and renders every git-repo external; specialized non-git externals remain separate. This keeps path consumers simple while making repository ownership, placement, gating, and destination uniqueness reviewable in one data file.

For projects we contribute to, `url` is our fork so `origin` is what `git push` targets, matching the layout `gh repo fork` produces. `upstream` then names the source of truth. chezmoi has no post-clone hook, so the upstream remote is injected through `clone.args` as `-c remote.upstream.*`; refresh runs a bare `git pull`, so `branch` names what it follows and `pull.args` points it at `upstream` whenever one is set. Without that redirect a 48h refresh would pull our own fork and never see upstream commits. `--ff-only` makes refresh abort rather than merge once a branch carries local work.

`clone.args` applies only when git clones, so a checkout that predates its entry's `upstream` would refresh against a remote it lacks. `run_onchange_after_120_reconcile-fork-remotes.sh.tmpl` renders from the same list and reconciles both remotes on existing clones. It rewrites rather than reports a wrong `origin`: for a fork entry that can only be leftover from an earlier entry, and it is not a remote we could push to.

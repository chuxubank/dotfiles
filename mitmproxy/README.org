* mitmproxy

** 启动

响应插件在 =mitmproxy-mock= skill 的 =scripts/map-local.py=。
=MITMPROXY_MOCK_DIR= 是 profile 根目录。未设置 =mock_profile= 时使用 =HOST_ENV=：
#+begin_src sh
  mitmdump --mode wireguard -s <skill>/scripts/map-local.py
#+end_src

换一套 profile 时加 =--set mock_profile=<name>=。

** 配置

=<name>= 是 =MITMPROXY_MOCK_DIR= 下的一个目录：
- =routes.json=：URL 匹配规则、响应文件和处理器名称。
- =data/=：本地 JSON 响应文件。
- =handlers.py=：可选的自定义处理器，以 =handle_= 为函数名前缀。

** 客户端连接

- 按启动提示在客户端导入 WireGuard 配置并连接。
- 访问 =http://mitm.it=，安装并信任本机 mitmproxy CA，以便调试 HTTPS 请求。
- 仅在授权的测试环境使用；调试结束后关闭隧道。
- WireGuard 客户端配置、二维码及 CA 私钥属于敏感文件，不要提交或公开分享。

前台运行时按 =Ctrl-C= 停止代理。
